# FEM–FNO для эллиптического уравнения

Проект исследует применение Fourier Neural Operator (FNO) для аппроксимации решений параметрического эллиптического уравнения

\[
-\nabla \cdot (a(x,y)\nabla u(x,y)) = f(x,y), \quad (x,y) \in \Omega=[0,1]^2,
\]

с граничным условием Дирихле

\[
u=0 \quad \text{на } \partial\Omega.
\]

Коэффициент диффузии `a(x, y)` генерируется как реализация Gaussian Random Field. Эталонные решения строятся методом конечных элементов (FEM) с помощью DOLFINx, после чего интерполируются на равномерную сетку `64×64` и используются для обучения FNO.

## Структура проекта

- `src/config.py` — параметры задачи, датасета, архитектуры и обучения.
- `src/generate_data.py` — генерация коэффициентов и FEM-решений.
- `src/dataset.py` — загрузка и нормализация датасета.
- `src/fno.py` — модель FNO на JAX/Flax.
- `src/train.py` — обучение, валидация и сохранение checkpoint.
- `src/evaluate.py` — оценка на тестовой выборке и расчет метрик.
- `src/visualize.py` — визуализация коэффициента, FEM-решения, предсказания и ошибки.
- `data/` — сгенерированный датасет.
- `checkpoints/` — сохраненные модели.
- `results/` — предсказания, метрики и изображения.

## Основные параметры

- область: `[0, 1]²`;
- FEM-сетка: `128×128`, элементы P1;
- сетка FNO: `64×64`;
- датасет: 800 обучающих, 100 валидационных и 100 тестовых примеров;
- FNO: ширина скрытого представления 32, 4 Fourier-слоя, 12 спектральных мод;
- вход модели: `a(x,y)` и координаты `x`, `y`;
- оптимизатор: Adam, начальный learning rate `1e-3`;
- метрики: relative L2 error, MSE и максимальная абсолютная ошибка.

## Установка

Для Python-зависимостей используется `uv`:

```powershell
uv sync
```

Генерация FEM-данных требует отдельной установки DOLFINx, а также `mpi4py`, `petsc4py` и UFL. DOLFINx не следует устанавливать командой `pip install dolfinx`: используйте рекомендованное разработчиками DOLFINx Conda-окружение или готовую специализированную сборку.

После настройки окружения можно проверить доступность FEM-библиотеки:

```powershell
uv run python -c "import dolfinx; print(dolfinx.__version__)"
```

Для проверки устройства JAX:

```powershell
uv run python -c "import jax; print(jax.devices())"
```

## Запуск полного pipeline

Команды выполняются из корня репозитория и в указанном порядке:

```powershell
# 1. Сгенерировать датасет через DOLFINx
uv run python src/generate_data.py

# 2. Обучить FNO
uv run python src/train.py

# 3. Оценить модель на тестовой выборке
uv run python src/evaluate.py

# 4. Построить визуализацию
uv run python src/visualize.py
```

Скрипты импортируют модули из каталога `src`, поэтому запуск из корня проекта является предпочтительным. Для запуска в виде модулей можно добавить `src` в `PYTHONPATH`.

После генерации данных создается файл:

```text
data/elliptic_dataset.npz
```

Обучение сохраняет лучшую модель в `checkpoints/best_model.pkl`. Оценка записывает `results/test_metrics.json` и `results/test_predictions.npz`, а визуализация — изображения в `results/`.

## Быстрый отладочный запуск

Для проверки pipeline на уменьшенном объеме данных в `Config` предусмотрен метод `Config.apply_debug_mode()`. Он уменьшает размеры train/validation/test, число эпох и параметры модели. Этот режим предназначен для проверки установки и интерфейсов, а не для получения итоговых результатов.

## Метрики

Основная метрика — относительная L2-ошибка:

\[
\operatorname{rel\_L2}(u_{pred},u_{true})=
\frac{\|u_{pred}-u_{true}\|_2}{\|u_{true}\|_2+10^{-8}}.
\]

Также вычисляются среднеквадратичная ошибка (`MSE`) и максимальная абсолютная ошибка (`max_error`).
